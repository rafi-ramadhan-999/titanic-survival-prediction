# Titanic Survival Prediction

A machine learning project to predict passenger survival on the Titanic dataset.

## Tools & Model

- Python
- Pandas
- Scikit-learn
- Random Forest

## Project Overview

This project analyzes the Titanic dataset and builds a machine learning model to predict whether a passenger survived based on available passenger features.

## Workflow

1. Data loading
2. Data exploration
3. Data preprocessing
4. Feature selection
5. Model training
6. Model evaluation

## Dataset

The project uses the Titanic dataset provided through Kaggle.

The notebook contains the complete analysis, model training process, and evaluation results.
